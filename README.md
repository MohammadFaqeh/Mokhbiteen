# مشروع المخبتين القرآني — لوحة شرف شهر 7

موقع ويب عربي (RTL) لعرض نتائج ولوحة شرف مجموعة قرآنية، مبني بالكامل بـ HTML5 وCSS3 وJavaScript عادي، دون أي Backend أو قاعدة بيانات. يعمل مباشرة عند فتح `index.html`، ومناسب للرفع على GitHub Pages مباشرة.

## هيكل الملفات

هذا كل شيء — مجلد واحد فيه 9 ملفات ومجلد صور، وليس مشروعين منفصلين.
صفحة `admin.html` هي مجرد صفحة إضافية داخل نفس المشروع (لوحة تحكم)، وليست مشروعًا مستقلًا.

```text
index.html          الصفحة العامة (تُعرض للطلاب والأهالي)
admin.html           لوحة تحكم لتعديل البيانات محليًا (محمية بكلمة مرور)
style.css            التصميم الكامل للموقع
data.js               جميع بيانات الطلاب والنتائج والنصوص
script.js             عرض البيانات، الحسابات، الحركات
admin.js              منطق لوحة التحكم، الحماية بكلمة المرور، وتصدير data.js محدّث
assets/logo.png        شعار المشروع
assets/mentor.jpg      صورة مشرف المشروع
assets/students/        مجلد لصور الطلاب الشخصية (اختياري)
```

## كيفية الرفع على GitHub Pages

1. أنشئ مستودعًا (repository) جديدًا على GitHub.
2. **افتح مجلد المشروع نفسه** (الذي بداخله `index.html` مباشرة)، وارفع **كل الملفات التي بداخله** (وليس المجلد نفسه) إلى جذر المستودع — أي يجب أن يظهر `index.html` مباشرة في الصفحة الرئيسية للمستودع، وليس داخل مجلد فرعي.
3. من إعدادات المستودع Settings → Pages، اختر الفرع (branch) الرئيسي كمصدر للنشر (Source: main / root).
4. بعد دقيقة أو دقيقتين سيصبح الموقع متاحًا على رابط من نوع:
   `https://username.github.io/repo-name/`
5. صفحة لوحة التحكم متاحة من الرابط الصغير أسفل الواجهة العامة، ويمكن فتحها مباشرة على:
   `https://username.github.io/repo-name/admin.html`

لا حاجة لأي بناء (build) أو تثبيت حزم — الملفات تعمل كما هي.

## حفظ لوحة الشرف كصورة

للتشغيل من الكمبيوتر وحفظ الصورة، افتح `start-site.bat` واترك نافذته مفتوحة. سيفتح الموقع على `http://127.0.0.1:8000/index.html`. الخادم مربوط بهذا الجهاز فقط ولا يقبل اتصالات من أجهزة الشبكة.

فتح `index.html` مباشرة بعنوان يبدأ بـ `file:///` يسمح بعرض الموقع، لكن المتصفح يمنع تصدير صور الطلاب إلى PNG لأسباب أمنية. يعمل الحفظ أيضًا بصورة طبيعية بعد نشر الموقع على GitHub Pages.

## لوحة التحكم (admin.html) — محمية بكلمة مرور

صفحة `admin.html` مقفلة بكلمة مرور حتى لا يستطيع أي زائر أو طالب فتحها والتعديل على البيانات. لا تُكتب كلمة المرور داخل ملفات المشروع أو التوثيق العام؛ يُحفظ فقط ملخصها المشفر داخل كود لوحة التحكم.

- عند إدخالها بشكل صحيح، تُفتح لوحة التحكم ولن تُطلب كلمة المرور مرة أخرى في نفس الجلسة على نفس الجهاز (حتى تُغلق المتصفح).
- هذه حماية أساسية من جهة المتصفح (client-side) فقط — تكفي لمنع الدخول العرضي من الطلاب أو الزوار، لكنها ليست بمستوى حماية خادم حقيقي (لا تستخدمها لبيانات حساسة جدًا).

**لتغيير كلمة المرور:**
1. افتح أي صفحة ويب، ثم افتح أدوات المطور (Developer Tools) واذهب لـ Console.
2. الصق الأمر التالي بعد استبدال `NEW_PASSWORD` بكلمة المرور الجديدة التي تريدها:
   ```js
   crypto.subtle.digest('SHA-256', new TextEncoder().encode('NEW_PASSWORD'))
     .then(b => console.log(Array.from(new Uint8Array(b)).map(x=>x.toString(16).padStart(2,'0')).join('')))
   ```
3. انسخ القيمة الطويلة التي تظهر (hash)، وضعها بدل القيمة الحالية في متغير `ADMIN_PASSWORD_HASH` في بداية ملف `admin.js`.
4. احفظ الملف وارفعه مكان القديم.

## تعديل البيانات

**الطريقة الأولى — لوحة التحكم (admin.html):**
افتح `admin.html`، أدخل كلمة المرور، عدّل بيانات الطلاب أو أيام الدوام أو النصوص التحفيزية، ثم اضغط "تصدير data.js" لتنزيل ملف بيانات محدّث. استبدل به ملف `data.js` القديم في المشروع (وارفعه على GitHub من جديد ليظهر للجميع).

### بدء شهر جديد

من قسم "إدارة الشهر واللقاءات" في لوحة التحكم:

1. اكتب اسم الشهر والسنة وعدد اللقاءات.
2. اضغط "بدء شهر جديد"؛ سيُنزل الموقع نسخة احتياطية من الشهر الحالي تلقائيًا.
3. ستبقى أسماء الطلاب وصورهم، وتُصفّر جميع الدرجات والنتائج.
4. اختر تاريخ كل لقاء من التقويم، ويمكنك إضافة لقاء أو حذفه.
5. أدخل الدرجات ثم صدّر `data.js` واستبدله بالملف الموجود في المشروع.

تتحدث عناوين الموقع وعدد اللقاءات والإحصائيات واسم صورة لوحة الشرف تلقائيًا حسب بيانات الشهر الجديد.

> ملاحظة: لوحة التحكم تحفظ مسودة تعديلاتك تلقائيًا في متصفحك (localStorage) حتى تُصدّرها، لكنها لا تُعدّل الموقع العام مباشرة — يجب تصدير الملف واستبداله يدويًا لتظهر التعديلات للجميع.

**الطريقة الثانية — التعديل المباشر:**
افتح `data.js` بأي محرر نصوص، وعدّل القيم مباشرة. الملف منظم ومرتب بتعليقات عربية واضحة.

## إضافة صور الطلاب

ضع صورة الطالب داخل `assets/students/`، ثم أضف الحقل التالي داخل كائن الطالب في `data.js`:

```js
"photo": "assets/students/اسم-الملف.jpg"
```

سيستخدم الموقع الصورة تلقائيًا بدل الأفاتار الافتراضي (الحرفين الأولين من الاسم).

## آلية احتساب المعدل

```text
المعدل النهائي = الدوام × 10% + الحفظ × 30% + المراجعة × 30% + جدول العبادات × 20% + التقييم × 10%
```

يُحسب المعدل تلقائيًا داخل لوحة التحكم عند أي تعديل، ويُقرَّب لمنزلة عشرية واحدة.

## المكتبات المستخدمة (عبر CDN فقط)

- **Font Awesome** — الأيقونات
- **Chart.js** — رسم بياني صغير لأداء كل طالب داخل نافذة تفاصيله
- **html2canvas** — لحفظ منصة التتويج كصورة قابلة للمشاركة
- **خط Cairo / Aref Ruqaa** — عبر Google Fonts

لا يوجد أي استخدام لـ React أو Next.js أو npm أو أي Backend أو قاعدة بيانات.
